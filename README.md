# Computer Graphics Lab

**Subject:** Computer Graphics  
**Language:** C++  
**Graphics Library:** SDL2  
**Compiler:** GCC / MinGW64  
**IDE:** Visual Studio Code

## About the Repository

This repository contains practical assignments performed as part of the Computer Graphics Laboratory.

The assignments demonstrate the implementation of basic computer graphics concepts and drawing algorithms using C++ and the SDL2 graphics library.

## Assignments

### Assignment 1 – Basic Geometric Shapes
- Drawing a straight line
- Drawing a circle using the Midpoint Circle Algorithm
- Drawing a rectangle
- Drawing a triangle

### Assignment 2 – DDA Line Drawing Algorithm
- Implementation of the Digital Differential Analyzer (DDA) algorithm
- Accepting starting and ending coordinates from the user
- Calculating dx, dy and the number of steps
- Calculating X and Y increments
- Plotting pixels to generate a straight line
